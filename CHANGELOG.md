## [1.0.0] - 2026-10-11

First release candidate; publication and native installation QA are pending.

### Added

- Local audio playback with Web Audio analysis
- Windows system audio visualization through WASAPI loopback
- Now-playing metadata and media-key control through the System Media Transport Controls
- YouTube links that open in the browser, with the visuals following system audio on Windows
- Ten audio-reactive WebGL2 shader worlds with a CRT-glass post-processing pass
- Eight skins and a selectable glow colour (skin, shader or custom)
- Compact and resizable window with a remembered position
- Project website with licence, privacy and third-party notices pages
- macOS 14.2+ universal local-file playback preview from the same source tree
- Continuous integration for web and Windows/macOS Rust checks
- Manual Windows/Mac packaging with optional draft beta release and Mac notarization
- Vercel static website configuration and public-download SHA-256 verification
