# Code of Conduct

## Our pledge

We want this project to be a welcoming place for everyone, regardless of background, experience, identity or appearance. We pledge to take part in a respectful and constructive way.

## Expected behaviour

- Be respectful and assume good intent.
- Give and accept constructive feedback.
- Focus on what is best for the project and its users.

## Unacceptable behaviour

- Harassment, insults or personal attacks.
- Trolling, discriminatory jokes or unwelcome sexual attention.
- Publishing others' private information without permission.
- Other conduct that a reasonable person would find inappropriate in a professional setting.

## Enforcement

Report concerns privately through a [GitHub security advisory](https://github.com/ripplewaters/Nitrowave-Aero-1.0/security/advisories/new), or contact the maintainer on GitHub. Maintainers will review reports and may remove comments, commits, issues or contributors that break these expectations.

This Code of Conduct adapts the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
